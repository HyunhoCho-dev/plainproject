# DESIGN.md — 집중 지원 앱

UI를 만들 때 반드시 따라야 하는 규칙이다. 여기에 정의된 토큰만 사용한다.
**여기 없는 색·크기·간격을 새로 만들지 않는다.** 필요하면 먼저 물어본다.

---

## 1. 비주얼 테마 & 분위기

**조용한 작업 도구.** 사용자를 재촉하거나 혼내지 않는다.

이 앱은 사용자의 앱 사용을 차단한다. 그래서 톤이 조금만 어긋나도 "감시당한다"는 인상이 된다.
경고색, 느낌표, 강한 대비, 진동하는 애니메이션을 쓰지 않는다. 차단 화면조차 안내문의 톤을 유지한다.

**두 개의 모드가 있다.**

| 모드 | 적용 화면 | 인상 |
|---|---|---|
| 일반 (라이트) | 계획, 통계, 마이페이지, 설정, 온보딩, 인증 | 종이 같은 오프화이트. 얇은 선. 장식 없음 |
| 집중 (다크) | **포커스 타이머, 차단 오버레이 — 이 둘만** | 어둡고 조용함. 요소 수를 최소로 |

집중 모드를 앱 전체로 확대하지 않는다. 세션 중에도 계획·통계를 확인하는 동선이 있고, 그때마다 화면이 어두우면 피로하다.
다크는 "지금은 다른 상태"를 알리는 신호로만 쓴다.

## 2. 컬러 팔레트 & 역할

### 토큰

```css
:root {
  /* 배경 · 표면 */
  --bg:            #FBFBFA;
  --surface:       #FFFFFF;
  --surface-2:     #F4F4F2;

  /* 텍스트 */
  --text:          #1A1D23;
  --text-2:        #4B5563;
  --text-3:        #9AA1AC;

  /* 선 */
  --border:        #E8E8E6;
  --border-strong: #D5D5D2;

  /* 액센트 — 사용자 행동 */
  --accent:        #3A6FF7;
  --accent-weak:   #EBF1FE;

  /* AI — AI가 만들거나 판단한 것 전용 */
  --ai:            #7C5CE0;
  --ai-weak:       #F2EDFD;

  /* 의미 */
  --success:       #16A34A;
  --warn:          #D97706;
  --danger:        #DC2626;
}

[data-mode="focus"] {
  --bg:            #12141A;
  --surface:       #1C1F27;
  --surface-2:     #242833;

  --text:          #ECEEF3;
  --text-2:        #A8AFBD;
  --text-3:        #6B7280;

  --border:        #2A2E38;
  --border-strong: #3A3F4B;

  --accent:        #5B8CFF;
  --accent-weak:   #1B2440;

  --ai:            #9B82F0;
  --ai-weak:       #241E3A;

  --success:       #34D399;
}
```

### 역할 규칙

**`--accent` (파랑) 는 사용자가 하는 것에만.**
주요 버튼, 선택된 탭, 포커스 링, 진행 중 표시, 진행바. 화면당 눈에 띄는 액센트 면적은 한 곳으로 제한한다.

**`--ai` (보라) 는 AI가 한 것에만.**
AI 배지, AI 인사이트 카드, AI가 붙인 카테고리 태그, AI 분석 로딩 화면, 'AI 추천' 구분 배지.
사용자가 직접 추가한 항목에는 절대 쓰지 않는다. 이 규칙이 지켜지면 사용자는 색만 보고 출처를 안다.

**`--danger` (빨강) 는 파괴적 행동에만.**
회원 탈퇴, 계획 삭제 확인. **차단 오버레이에는 쓰지 않는다.**

**완료 상태**는 색을 쓰지 않는다. `--text-3` + 취소선으로 톤을 낮춘다.

## 3. 타이포 규칙

### 폰트

```css
--font-sans: 'Pretendard Variable', Pretendard, -apple-system,
             'Segoe UI', 'Malgun Gothic', sans-serif;
--font-num:  'SF Pro Display', -apple-system, 'Segoe UI', sans-serif;
```

숫자는 **항상** `font-variant-numeric: tabular-nums`. 타이머 숫자가 매초 흔들리는 것을 막는다.

### 스케일

| 토큰 | size / line-height / weight | 용도 |
|---|---|---|
| `display` | 56 / 1.0 / 700 | 타이머 경과 시간 |
| `h1` | 28 / 1.3 / 700 | 화면 제목, 통계 대표 수치 |
| `h2` | 20 / 1.4 / 600 | 섹션 제목, 스탯 타일 수치 |
| `h3` | 17 / 1.4 / 600 | 카드 제목, 일정 이름 |
| `body` | 15 / 1.6 / 400 | 본문 |
| `body-sm` | 14 / 1.5 / 400 | 보조 본문, 리스트 항목 |
| `caption` | 13 / 1.4 / 500 | 시각, 보조 설명 |
| `micro` | 11 / 1.3 / 600 | 배지 |

### 자간

- `display` : `-0.02em`
- `h1` `h2` : `-0.01em`
- 그 외 : `0`

한글 본문에 음수 자간을 크게 주지 않는다. 받침이 뭉친다.

## 4. 컴포넌트 스타일

정의된 컴포넌트는 **20개**다. 새 컴포넌트를 만들기 전에 이 목록으로 해결되는지 먼저 본다.

핵심 12개 — `plan-block` `stat-tile` `ai-card` `ai-badge` `bottom-sheet` `overlay`
`segment` `toggle-row` `chip` `empty-state` `skeleton` `banner`

화면을 만들며 추가된 8개 — `goal-card` `ring` `dialog` `field` `steps` `appcard` `bars` `social`

### `plan-block` — 계획 블록
- `--surface` 배경, `1px --border`, radius `--r-lg`, padding `--space-4`
- 좌측 원형 체크박스 24px (탭 → 즉시 완료)
- 우측 상단 배지: `AI 추천`(ai-badge) 또는 `직접 추가`(중립 배지)
- 시각은 `caption --text-2`, 일정 이름은 `h3`
- **상태 3종**
  - 예정 — 기본
  - 진행중 — `2px --accent` 테두리 + 좌상단 `▸ 진행중` 라벨(`micro --accent`)
  - 완료 — 이름에 취소선, 전체 `--text-3`, 배경 `--surface-2`
- 롱프레스 → `bottom-sheet` 열림

### `stat-tile` — 통계 타일
- 2×2 그리드, gap `--space-3`
- `--surface-2` 배경, radius `--r-lg`, padding `--space-4`
- 위: 라벨 `caption --text-2` / 아래: 수치 `h2` (숫자 tabular)

### `ai-card` — AI 인사이트 카드
- `--ai-weak` 배경, `1px` 테두리 없음, radius `--r-lg`, padding `--space-5`
- 최상단 `ai-badge`, 본문 `body` 1~2문장, 하단 보조 버튼
- 통계 페이지 최하단, 계획 생성 결과 화면에만 등장

### `ai-badge` — AI 배지
- 높이 20px, padding 0 8px, radius `--r-full`
- `--ai-weak` 배경 + `--ai` 텍스트, `micro`
- 좌측에 4px 점 또는 ✦ 글리프

### `bottom-sheet` — 하단 시트
- 화면 하단 부착, 상단 radius `--r-xl`, 배경 `--surface`
- 상단 중앙 드래그 핸들 36×4, `--border-strong`
- padding `--space-5`, 배경 딤 `rgba(0,0,0,.32)`
- 용도: 계획 인라인 수정 / "왜 추천됐나요?" / "AI가 무엇을 기준으로 판단하나요?"

### `overlay` — 전면 오버레이
- `data-mode="focus"` 고정, 전체 화면, 중앙 정렬
- 4블록 세로: 차단 사유 → 남은 세션 시간(`h1`) → 행동 버튼 → `차단 목록에서 제외` 텍스트 링크
- 행동은 `계속 집중하기`(primary) / `5분만 허용`(outline) / `차단 목록에서 제외`(text)
- **해제 경로를 숨기지 않는다.** 텍스트 링크로 두되 폭 100%, 터치 타겟 44px 이상을 유지한다
- 빨강·느낌표·자물쇠 금지

### `segment` — 세그먼트 탭
- `--surface-2` 트랙, radius `--r-full`, 내부 패딩 3px
- 선택 항목만 `--surface` + 미세 그림자, 텍스트 `body-sm 600`
- 용도: 통계 [주간 | 월간]

### `toggle-row` — 설정 행
- 높이 최소 56px, 좌측 라벨 `body`, 우측 스위치 51×31
- 하위 설명이 있으면 라벨 아래 `caption --text-2`
- 구분선은 `1px --border`, 좌측 인셋 `--space-5`

### `chip` — 선택 칩
- 높이 36px, padding 0 14px, radius `--r-full`, `1px --border`
- 선택 시 `--accent-weak` 배경 + `--accent` 테두리·텍스트
- 용도: 현재 수준(초급/중급/고급), 알림 시간(5/10/15/30분)

### `empty-state` — 빈 상태
- 세로 중앙, 아이콘 없이 문구 + 버튼만
- 문구 `body --text-2`, 아래 주요 버튼
- 문구는 명세 확정본을 그대로 쓴다 (§7 참조)

### `skeleton` — 로딩 자리표시
- `--surface-2` 채움, radius `--r-md`
- 1.4s ease-in-out 무한 왕복, opacity .6 ↔ 1
- **스피너를 쓰지 않는다.** 들어갈 내용의 모양 그대로 회색 블록을 놓는다

### `banner` — 상단 고정 배너
- 화면 최상단 부착, 높이 40px, `--surface-2` 배경, `caption`
- 용도: 오프라인 상태 알림

---

다음 8개는 화면을 만들며 추가됐다.

### `goal-card` — 목표 요약 카드
- 목표명 + D-day(우상단) / 달성률 `h1` + 시간 대비 / 하단 `gauge` 6px
- 모바일은 세로 조립, PC는 `--wide` 변형으로 좌우 배치
- 등장 위치: 홈 상단, 마이페이지 ②구역

### `ring` — 원형 진행바
- 260×260, `stroke-width` 10, `stroke-linecap: round`, `-90deg` 회전으로 12시 시작
- 트랙 `--surface-2`, 바 `--accent`
- 중앙에 `display` 경과 시간 + `caption` 보조 문구
- 포커스 타이머 전용

### `dialog` — 확인 다이얼로그
- 화면 중앙, 폭 `100% - --space-10`, radius `--r-lg`, 배경 딤 32%
- 제목 `h2` / 본문 `body --text-2` / 하단 버튼 2개 균등 그리드
- 파괴적 확인은 오른쪽 버튼을 `--danger`로
- 용도: 계획 재생성, 회원탈퇴 최종 확인

### `field` — 입력 필드
- 높이 52px, radius `--r-md`, `1px --border`
- 포커스 시 테두리 `--accent` + `3px --accent-weak` 링
- 하위 변형: `field__area`(최소 132px), `otp`(6칸 56px), `stepper`(±48px 원형 버튼)
- 도움말 `--text-3`, 오류 `--danger`

### `steps` — 단계 인디케이터
- 3px 높이 바를 균등 분할, 완료 구간만 `--accent`
- 온보딩 3단계, 회원가입 4단계 상단에 배치

### `appcard` — 차단 앱 카드
- 40px 아이콘 / 앱 이름 + 카테고리 태그 + '왜 추천됐나요?' / 우측 토글
- 카테고리 태그는 `--ai` 계열 (AI가 붙인 것). 사용자가 고치면 `--accent` 계열로 바뀌고 카드 테두리가 `--accent`가 된다
- AI 3종 세트가 한 컴포넌트에 모두 들어간 예시다

### `bars` — 막대그래프 / `spark` — 스파크라인
- `bars` 높이 148px(PC 200px), 막대 최대 24px, radius `--r-sm`
- 기본 `--accent-weak`, 오늘만 `--accent`
- `spark`는 마이페이지 미리보기용 44px 높이 축소판. 7개 고정

### `social` — 소셜 로그인 버튼
- 높이 52px, 전체 폭. 카카오 `#FEE500` / 네이버 `#03C75A` / 구글 `--surface` + 테두리
- **브랜드 컬러는 토큰 규칙의 예외다.** 각 플랫폼 가이드를 따라야 하므로 하드코딩을 허용한다
- 순서는 카카오 → 네이버 → 구글로 고정

## 5. 레이아웃 원칙

### 프레임
- 기준 해상도 **375 × 812** (iPhone 기준)
- 화면 좌우 패딩 `--space-5` (20px)
- 하단 탭바 높이 56 + safe-area
- 진행 중 미니바 높이 48, 탭바 바로 위에 붙음

### 간격 토큰 (4px 그리드)

```css
--space-1: 4px;   --space-2: 8px;   --space-3: 12px;
--space-4: 16px;  --space-5: 20px;  --space-6: 24px;
--space-8: 32px;  --space-10: 40px; --space-12: 48px;
```

### 형태 토큰

```css
--r-sm: 8px;    /* 배지, 작은 태그 */
--r-md: 12px;   /* 버튼, 입력 */
--r-lg: 16px;   /* 카드, 계획 블록 */
--r-xl: 20px;   /* 바텀시트 상단 */
--r-full: 9999px;
```

### 내비게이션

하단 탭 **3개** — `홈(계획)` `통계` `마이페이지`

타이머는 탭에 넣지 않는다. 계획 블록에서 시작하는 것이 정상 동선이라 탭으로 두면 대부분 비어 있다.
대신 **집중 세션 진행 중일 때만** 탭바 위에 미니바가 나타난다.

```
🔵 집중 중 · 기출문제 풀이 · 24:13        [탭 → 타이머 전체화면]
```

차단 앱 관리, 알림 설정, 계정 관리는 마이페이지 > 설정 리스트에서 진입한다.

**PC 웹에서의 대응** — 목적지는 동일하고 위치만 바뀐다.

| 모바일 | PC |
|---|---|
| 하단 탭 3개 | 좌측 사이드바 3개 (같은 순서) |
| 진행 중 미니바 (세션 중에만) | 우측 패널의 진행 중 세션 카드 (상시) |
| 프로필·스트릭은 마이페이지 안 | 사이드바 하단 유저 칩에 상시 노출 |

PC는 화면이 넓으므로 세션 상태를 숨겼다 보였다 하지 않는다. 자리를 항상 확보한다.

### 세로 리듬
- 섹션 사이 `--space-8`
- 카드 사이 `--space-3`
- 리스트 항목 사이 `0` (구분선으로 나눔)

## 6. 깊이 & Elevation

**그림자를 거의 쓰지 않는다.** 깊이는 표면 단계와 얇은 선으로 만든다.

| 단계 | 라이트 | 다크 |
|---|---|---|
| 0 — 캔버스 | `--bg` | `--bg` |
| 1 — 카드 | `--surface` + `1px --border` | `--surface` + `1px --border` |
| 2 — 눌린 영역 | `--surface-2`, 선 없음 | `--surface-2`, 선 없음 |
| 3 — 떠 있는 것 | `--surface` + 그림자 | `--surface-2` + `1px --border-strong` |

그림자는 3단계(바텀시트, 세그먼트 선택 알약, 하단 고정 저장 버튼)에만:

```css
--shadow: 0 4px 16px rgba(26, 29, 35, .08);
```

다크 모드에서는 그림자가 보이지 않는다. 다크에서는 그림자 대신 **테두리를 한 단계 밝게** 한다.

## 7. Do's and Don'ts

### Do

- **AI가 만든 것에는 항상 세 가지를 붙인다** — ① AI 배지 ② 근거를 볼 진입점 ③ 사용자가 뒤집을 수단. 예외 없다
- 숫자를 화면의 주인공으로 둔다. 화면마다 큰 숫자 하나
- 사용자 수정은 즉시 반영하고 결과를 알린다 ("이 선택을 기억할게요")
- 터치 타겟 최소 44 × 44
- 완료·차단 같은 상태 변화는 색 하나로 표현한다. 아이콘까지 함께 바꾸지 않는다

### Don't

- **차단 화면에 빨강, 느낌표, 자물쇠 아이콘을 쓰지 않는다.** 이 앱은 사용자를 벌주지 않는다
- 액센트색을 한 화면에 여러 곳에 뿌리지 않는다
- 보라(`--ai`)를 장식으로 쓰지 않는다. AI가 개입하지 않은 요소에 쓰면 규칙이 무너진다
- 그라디언트, 글래스모피즘, 큰 그림자를 쓰지 않는다
- 스피너를 쓰지 않는다. 스켈레톤을 쓴다
- 집중 모드 다크를 타이머·차단 오버레이 밖으로 확대하지 않는다
- 빈 상태에 일러스트를 넣지 않는다. 문구와 버튼이면 충분하다

### 확정 문구 — 그대로 사용

명세에서 확정된 문구다. 임의로 바꾸지 않는다.

| 상황 | 문구 |
|---|---|
| AI 계획 생성 실패 | "계획을 만드는 데 문제가 생겼어요" + 다시 시도 버튼 |
| 네트워크 끊김 | "오프라인 상태예요, 일부 기능이 제한돼요" (상단 고정 배너) |
| 계획 없는 첫 홈 | "목표 입력하고 첫 계획 받기" (CTA 카드) |
| 통계 데이터 없음 | "아직 기록된 학습 데이터가 없어요. 첫 타이머 세션을 시작해보세요" |
| 패턴 분석 데이터 부족 | "아직 패턴을 분석하기엔 데이터가 부족해요 (앞으로 D일 더 필요)" |
| 알림 권한 요청 | "AI는 어떤 앱을 얼마나 사용했는지, 알림을 보낸 앱 이름만 확인하며 메시지·게시물 내용은 읽지 않습니다" |
| 통계 갱신 시각 | "마지막 업데이트: 오늘 오전 6시" |
| 계획 재생성 확인 | "완료한 일정은 유지하고 남은 일정만 다시 짤까요?" |
| 카테고리 수동 변경 | "이 선택을 기억할게요" (토스트) |
| 회원 탈퇴 경고 | "탈퇴 시 집중 기록과 통계가 모두 삭제되며 복구할 수 없습니다" |

## 8. 반응형 동작

표면이 두 개다. **모바일 앱**(주력)과 **PC 웹**. 토큰과 컴포넌트는 완전히 공유하고, **배치만 다르게** 한다.

### 모바일 앱

| 폭 | 처리 |
|---|---|
| < 360 | 좌우 패딩 `--space-4`로 축소. `display` 48px로 축소 |
| 360 – 430 | **기준.** 375 기준으로 설계하고 유동 폭으로 늘어남 |
| > 430 | 콘텐츠 폭을 430으로 고정하고 가운데 정렬. 좌우는 `--surface-2` |

### PC 웹

| 폭 | 처리 |
|---|---|
| ≥ 1200 | **기준.** 사이드바 240 + 본문(최대 720) + 우측 패널 300. 우측 패널 sticky |
| 1024 – 1199 | 우측 패널을 본문 **위로** 올려 가로 배치. 본문 폭 제한 해제 |
| < 1024 | 사이드바를 72px 아이콘 전용으로 축소 |
| < 768 | 모바일 레이아웃으로 전환 (하단 탭바) |

**진행 중 세션 카드는 어떤 폭에서도 계획 목록보다 위에 있어야 한다.** 실행 중인 타이머가 스크롤 아래로 밀리면 안 된다.

### 공통

- 모든 폭 값은 `%` 또는 `flex`. 고정 px 폭을 쓰지 않는다 (사이드바·우측 패널 제외)
- 2×2 스탯 그리드는 어떤 폭에서도 2열을 유지한다
- 세로 스크롤만 허용한다. 가로 스크롤이 생기면 버그다 (모바일 날짜 스트립만 예외)
- 본문 텍스트 컬럼은 720px를 넘기지 않는다. 넘으면 읽기 어렵다

## 9. Agent Prompt Guide

이 프로젝트에서 UI를 만들 때:

1. **작업 전 이 파일을 읽는다.** 화면 하나를 만들 때마다 읽는다
2. **토큰 이름으로 쓴다.** `#3A6FF7`이 아니라 `var(--accent)`. 하드코딩된 색·간격이 보이면 잘못된 것이다
3. **§4의 20개 컴포넌트로 먼저 조립을 시도한다.** 안 되면 새로 만들지 말고 물어본다
4. **§7의 확정 문구는 글자 그대로 쓴다**
5. 다크가 필요한 화면은 루트에 `data-mode="focus"`만 붙인다. 별도 CSS를 쓰지 않는다
6. 새 토큰이 필요하면 이 파일을 먼저 고치고 나서 사용한다
